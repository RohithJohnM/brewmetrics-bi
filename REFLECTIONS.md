# Reflection

Working on the BrewMetrics project with Copilot made the development process much easier, especially when creating DAX measures and writing the project documentation. Some of Copilot’s suggestions could be used almost directly. The Month-over-Month Sales Growth measure worked well with my existing date relationship, and the Average Sale Amount measure also fit the model without major changes. The Item Sales Rank measure was useful as well because it followed the required `RANKX` approach.

At the same time, I learned that Copilot’s suggestions should not simply be copied without checking them. The biggest correction I made was to the Cumulative Sales measure. Copilot initially used `ALL(Dim_Date)`, but I changed it to `ALL(Dim_Date[date])` so that the calculation removed only the date filter instead of affecting the whole date table. I also reviewed the README generated by Copilot and removed details that were not actually confirmed by my model or dashboard.

The commit history also changed the way I approached this Power BI project. In a normal single-file lab, I would usually build everything first and submit the final report. Here, I had to think about each stage separately and commit the star schema, individual measures, dashboard, and documentation as the project developed. This made me more careful with my changes and helped me keep track of how the project evolved.
